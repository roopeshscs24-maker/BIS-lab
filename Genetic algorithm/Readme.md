Genetic Algorithm for Optimization
Problem statement
Hospital Staff Scheduling Optimization

Consider a hospital with:
- 6 nurses.
- 7 working days.
- 3 available examination shifts (Morning, Evening, Night).
- 8 hours per shift.
- Each shift requires one nurse.
- Each nurse can work a maximum of 5 shifts per week.
- Nurses have different availability.
- Nurses must have sufficient rest between shifts.
The algorithm must assign nurses to different shifts while minimizing workload imbalance and scheduling conflicts.
