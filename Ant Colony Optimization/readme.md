Problem Statement: Resource Scheduling Optimization Using Ant Colony Optimization
Consider an organization with:
- 5 available resources (R1, R2, R3, R4, R5).
- 8 tasks that need to be completed.
- 3 available working shifts (Morning, Afternoon, Night).
- Each task requires a specific amount of resources.
- Each resource has a limited working capacity.
- Tasks have different execution times and priorities.
- Some tasks must be completed before other tasks.
- Resources have different availability.
- Each resource can handle only one task at a time.
- The algorithm must assign resources to different tasks while minimizing total project completion time and workload imbalance.
Objective: Minimize the total project completion time while satisfying resource availability and task dependency constraints.
